# 一致性出图画布（nuv）

自用的无限画布出图工作台：节点连线式出图，接自己的 API 或中转站，并用「产品卡」「人物卡」锁住产品和人物的一致性。

本项目基于开源项目 [basketikun/infinite-canvas](https://github.com/basketikun/infinite-canvas)（MIT 许可）修改，在其上增加了一致性卡功能。原项目说明见 [docs/UPSTREAM_README.md](docs/UPSTREAM_README.md)。

## 三步上手

1. **填接口**：右上角「配置」里填中转站（或官方）的 Base URL 和 API Key，选好生图模型。兼容 OpenAI 接口的服务都能接。
2. **建卡**：进入一个画布，左侧面板选「一致性卡」，新建产品卡 / 人物卡：上传 2–4 张参考图，写下不能变的要点。
3. **连线出图**：点卡片把它放上画布，从卡片分组右侧的小圆点拉线到空白处，选「图片生成」；再把人物卡、场景模板也连到这个图片节点上，写画面描述，点发送。

## 一致性卡是怎么起作用的

- 一张卡放到画布上是一个分组：几张参考图 + 一段锁定文字。
- 连到生成节点后，分组里的图片和文字会一起发给模型，并且自动写明“图片1、图片2 是产品「××」”“图片3、图片4 是人物「××」”，让模型分清谁是谁。
- 每次修改卡片版本号 +1，分组标题带版本号，方便回查某张图用的是哪一版。
- 满意的虚拟模特图：在画布上选中它，新建人物卡时点「加入画布上选中的图片」，以后每次都引用这张卡。

## 数据存在哪

画布、卡片、图片和 API Key 都只保存在本机浏览器里，出图请求由浏览器直接发往你填的接口。清除浏览器数据前请先在「配置 → 本地存储」里导出备份。

## 本机运行（开发）

```bash
cd web
pnpm install
pnpm dev      # 打开 http://localhost:3000
```
