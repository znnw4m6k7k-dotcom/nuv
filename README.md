# 一致性出图画布

自己用的无限画布出图工作台：用「产品卡」「人物卡」锁住产品和人物的一致性，接自己的 API 出图。

## 怎么打开

下载本仓库（Code → Download ZIP），解压后用 Chrome 双击 `index.html` 即可，不需要安装任何东西。

## 怎么用

1. 右上角 **API 设置**：填接口地址、API Key、模型名称（默认 OpenAI 的 `gpt-image-1`，任何兼容 OpenAI 图像接口的服务都能接）。
2. 左侧新建 **产品卡 / 人物卡**：上传 2–4 张参考图，写下不能变的要点。
3. 右侧选 **场景**（电商主图、模特上身图、场景种草图、视频分镜、自由），写画面描述，点 **生成**。
4. 结果按批次排在画布上。选中图片可以并排对比、和参考图对比、设为参考图、复用参数、存入资产卡、下载。

## 画布操作

- 拖动空白处平移；双指或 ⌘/Ctrl＋滚轮缩放
- Shift＋拖动框选；Delete 删除
- 图片可以直接拖进或粘贴进画布
- 双击图片放大并查看它的完整生成参数

## 数据存在哪

所有图片、资产卡和 API Key 都只存在本机这个浏览器里（IndexedDB），不上传到任何服务器。
清除浏览器数据或换电脑前，请用右上角 **备份** 导出。

## 文件

- `index.html` 页面结构
- `style.css` 样式
- `app.js` 全部逻辑（无依赖、无构建）
